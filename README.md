# 链接失效核验工具

面向中文内容平台和新闻网站的 Windows 批量链接状态核验工具。当前版本为 4.5.5。

支持百度贴吧、百度知道、百度文库/百科、百家号、百度共享页，以及微博、知乎、抖音、快手、B站、雪球、懂车帝、小红书、简书、汽车之家论坛、虎扑、豆瓣、CSDN、掘金、NGA、天涯等平台；未知域名仍按通用网页证据规则处理，不会因平台名缺失而强判。

工具把结论分为“仍可访问”“已失效”“暂时异常”和“人工复核”。确定结论必须有目标内容编号、标题、正文、作者、平台官方状态或明确目标错误页等证据。账号名、标题和正文可能在发布后被修改；对能提供可靠结构化数据的平台，工具会以不可变目标编号、当前公开状态和非空当前正文/媒体数据确认内容仍在，并把标题、作者差异作为变更提示。只有编号的空壳页、缓存页或空接口仍不足以证明有效。HTTP 200、403、502、登录页、验证码、WAF 和通用页面本身也都不足以证明内容有效或失效。

快速阶段可选启用大模型候选复核：`Run-ShardedFastAudit.ps1 -AiMode shadow` 只记录 AI 建议，不改变规则结论；`-AiMode assist` 仅在本地身份安全门通过时允许确认“仍可访问”，不会把 AI 单独当作下架证据。候选默认最多 50 条、3 路并发，可用 `-AiMaxCandidates` 和 `-AiWorkers` 调整。未配置本机加密保存的 AI Token/模型时自动跳过。403、5xx、验证码、登录壳、空壳和超时不会进入 AI 候选队列。

使用 `-LoginFirst` 时，登录准备得到的 Cookie 会以当前 Windows 用户 DPAPI 加密到本次输入对应的临时文件，供后续分片进程复用；任务结束自动删除。Cookie 只进入本地目标请求，不会进入公共阅读器、结果、日志或 Git。

注意：AI 候选复核不会代替登录、验证码或网络线路补证。2026-08-07 使用第 1 轮 240 条原始样本复跑时，普通快速阶段为 27/240（11.25%）未完成；开启独立公开补证后为 26/240（10.83%），耗时约由 57 秒增至 113 秒，尚未达到严格低于 5% 的验收门槛。

## 使用

1. 下载并完整解压便携包。
2. 双击 `启动工具.cmd`。
3. 粘贴链接或导入 Excel。若包含微博、知乎、抖音、今日头条、懂车帝等平台，点击“开始检测”后可先完成一次“登录准备”；也可以跳过，直接按公开页面核验。
4. 登录准备只在本机当前进程内存中把会话 Cookie 桥接给快速核验，密码不会被工具读取，Cookie 不写入结果、日志或仓库，也不会发送给远程/公共取证节点。内置浏览器的登录状态保存在本机 WebView2 用户目录中，可能在下次启动时继续有效；“停止本次使用”只停止桥接，不会代替平台退出登录。登录状态只能帮助取得目标页面，不能单独证明内容有效。
5. 基础核验完成后，根据需要手动启动“自动补证”。

进度按任务逐条保存。程序中断后可以恢复上次核验，不会把未取得充分证据的链接自动归为有效。

### 大批量运行原则

几十万条数据建议使用 CSV 分批、断点续跑和固定代理出口。快速阶段会对同一批中完全相同的目标 URL 做单飞去重，并按平台/基础设施限速；只有带目标级正文、编号、公开状态或明确删除证据的结果才允许复用，403、验证码、WAF、502、超时和空壳结果不会被缓存成有效或失效。平台专用补证和浏览器补证应作为第二阶段队列，只处理快速阶段的未完成项，避免让全量任务被单一慢平台拖住。

建议把几十万条拆成每批 5,000—20,000 条，保留每批输出和检查点，先汇总确定结果，再对未完成项按平台重新排队。验收时必须报告总量、唯一 URL 数、去重数、各平台未完成率、出口/基础设施异常率和确定结论证据来源；不能用重复样本或历史结果替代当前真值。

完整操作说明见 `使用说明.txt`，判定边界见 `核验逻辑说明.txt`。

## 本地验证

首次构建会从 NuGet 下载 Microsoft WebView2 SDK：

```powershell
.\prepare-runtime.ps1
```

运行核心回归测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Run-CoreTests.ps1' -RegressionOnly
```

运行发布验证契约测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Test-ValidationScripts.ps1'
```

正式稳定性验收默认连续运行 10 轮，每轮从本地真实台账抽取 240 条未使用链接，
并要求每轮及累计未完成率都严格低于 5%：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Run-TenRoundValidation.ps1'
```

脚本保留逐轮结果、未完成项的平台/基础设施分布和汇总门禁；某一轮失败不会跳过后续轮次。
长时间任务中断后，使用相同输出目录、种子前缀并增加 `-Resume`，即可跳过已完成轮次并从未完成轮次继续。

如所在网络需要显式 HTTP 代理，可在启动前设置 `LINK_CHECKER_HTTP_PROXY`（例如
`http://127.0.0.1:7893`）。未设置时自动读取 Windows 固定 WinINET 代理及绕过列表（PAC/WPAD 仍交给系统代理）；代理、403、验证码或通用空壳都不会被当作目标内容已失效。

## 发布边界

没有足量、近期、人工确认的真值样本时，生成的包只能标记为候选版。轮换样本的确定率用于衡量覆盖能力，不等同于真实准确率，也不能代替人工验收。

本仓库不提交 API Token、Cookie、登录账号、运行日志、客户原始数据或本地核验结果。

## 大批量快速核验（几十万条）

对几十万条数据，使用 `开发文件\Run-ShardedFastAudit.ps1`，不要一次性把整本文件交给桌面窗口：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Run-ShardedFastAudit.ps1' `
  -InputCsv '.\input.csv' -OutputCsv '.\output.csv' -RowsPerShard 10000 -Workers 6 -Resume
```

如本批包含微信、知乎、微博等登录后才能取得目标正文的平台，可在首次运行增加 `-LoginFirst`，集中完成一次登录后继续快速核验；已有工具 WebView2 登录会话时可使用 `-UseSavedLogin` 静默加载。Cookie 只桥接到当前分片进程内存，后续分片从工具自己的 WebView2 配置重新读取，不写入结果、manifest 或公开仓库。

该流程按完整 CSV 记录流式分片，标题或摘要中的逗号、双引号和换行不会拆坏记录。每片独立输出并写入 manifest；默认开启快速阶段检查点，进程中断后可以从已完成片和片内检查点继续。全局编号按每片实际有效 URL 数量计算，不会因空行或无效链接错位。确定结果缓存按分片隔离，避免几十万条任务的后续进程反复加载越来越大的全局缓存；只复用“仍可访问/已失效”且带目标证据的结果，403、验证码、WAF、502、超时、登录壳和空壳页不会缓存为确定结论。同一共享基础设施连续失败后，后续同组条目会保留为待重试而不继续占满工作线程，也不会被改判成失效。

只验证几十万条输入的规划、记录完整性和资源占用，不发出网络请求：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Run-ShardedFastAudit.ps1' `
  -InputCsv '.\input.csv' -OutputCsv '.\output.csv' -RowsPerShard 10000 -PlanOnly
```

执行完成后除合并结果外，还会生成 `output.csv.summary.csv`，记录各平台的总量、确定数、未完成数和未完成率；manifest 同时记录全局未完成率及是否严格低于 5%。本地发布前测试入口：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Run-ShardedPlanningStressTest.ps1' -TotalRows 300000
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\开发文件\Run-ShardedExecutionSmokeTest.ps1'
```

速度优化不能替代准确性门禁。验收时应分别报告总行数、有效 URL 数、去重数、各平台未完成率和确定证据来源。30 万条本地规划压力测试只证明数据通道可以承载该数量级，不证明真实平台核验速度或准确率。一次定向重试样本曾达到 3.33%，但尚未通过 10 轮稳定性门禁；2026-08-07 的广覆盖新样本（80 个平台、161 个域名）因共享网媒基础设施大面积 502 而失败，不能作为达标轮次。
