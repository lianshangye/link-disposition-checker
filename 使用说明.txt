链接失效检测工具 - 使用说明
============================

当前版本：4.4.2

一、这个工具只做什么
--------------------

批量检测链接当前是：

- 有效：已经取得目标页面正文或可确认的目标内容。
- 失效：目标地址返回 404、410，或页面明确说明内容已删除、下线、不存在。
- 未完成：本轮受到 403、429、502、超时、验证码或探针额度影响，还没有足够证据。

“未完成”不是“失效”。工具会把这些链接保留给“继续未完成”，不会要求你逐条人工分类。

二、怎么使用
------------

1. 双击“启动工具.cmd”。
2. 粘贴链接，或选择 Excel / CSV。
3. 点击“开始检测”。
4. 检测结束后查看“有效、失效、未完成”数量。
5. 如果存在未完成项，点击“继续未完成”。
6. 点击“导出结果”保存 CSV；从 Excel 导入时可以把结果写回原文件，写回前会自动备份。

默认界面只保留：

- 开始检测
- 继续未完成
- 停止
- 导出结果
- 打开链接
- 运行日志

三、判定原则
------------

- HTTP 200 本身不够，必须同时取得文章标题、正文摘要或正文结构。
- HTTP 404、410 可以直接确认地址失效。
- 明确的“内容已删除、已下线、文章不存在”页面可以确认失效。
- 403、429、444、502、超时、连接失败、验证码和登录页都只算未完成。
- AI 不参与网络错误判断，也不会把错误页猜成有效或失效。

四、针对共享资讯站点
--------------------

部分站点在本机或境外线路返回 502，但中国普通宽带首次访问会返回防火墙 Cookie。
4.4 会自动：

1. 在中国普通宽带探针建立会话。
2. 携带 Cookie 再次访问原链接。
3. 如果仍然 403，立即合并新 Cookie 并重试。
4. 仍未成功时，为当前链接重新建立一次全新会话。
5. 按域名连续处理，尽量复用已经成功的会话。

工具不再因为同一 IP 或同一域名连续出现 502 就跳过后续链接。

五、外部探针额度
----------------

中国普通宽带取证使用 Globalping。匿名额度用完时，结果显示“未完成”，不会显示“公网不可访问”。
v4.4.1 起，探针控制 API 使用本机直连出口，不再与目标网页的系统代理共享匿名额度。

如已取得 Globalping Token，可在当前 Windows 用户环境中设置：

GLOBALPING_API_TOKEN

设置完成后无需删除旧结果，重新打开工具或直接点击“继续未完成”即可。Token 不会写入日志、CSV 或断点。

六、结果文件
------------

CSV 只包含：

- 序号
- 链接状态
- HTTP 状态
- 页面标题
- 原链接
- 最终地址
- 检测说明
- 检测时间
- 耗时

每次执行结束都会生成运行日志。发生问题时，把“最近一次执行日志.txt”发给维护者即可。

七、4.4 的主要变化
------------------

4.4.2 补充了跨电脑同步后的可靠性保护：

- 同一工作表同一行更换 URL 后会被视为新任务，不会误用旧结果。
- 主进度损坏时可从备份恢复；日志末行因中断不完整时，保留此前完整结果。
- 只有目标平台的最终地址返回 404/410 才能直接确认失效；跨站或登录页跳转不直接判失效。
- 关闭程序时等待最后一批结果写入断点。
- 支持没有 BOM 的 UTF-8 CSV，中文表头不会因编码误判而导入失败。

- 默认界面从十多个功能按钮缩减为六个核心操作。
- 去除默认界面中的合同、证据等级、供应商行动和 AI 设置。
- 结果统一显示为有效、失效、未完成。
- 旧版“公网不可访问”会在升级后自动进入未完成续检。
- 502 不再触发整组提前跳过。
- Globalping 429 不再被错误归类为公网不可访问。
- 防火墙 Cookie 失败时会在同一轮刷新并重建会话。
- 按域名连续检测，减少 Cookie 会话和探针额度浪费。
