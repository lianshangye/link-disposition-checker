链接失效检测工具 - 使用说明
============================

当前版本：4.5.5

一、这个工具只做什么
--------------------

批量检测链接当前是：

- 有效：已经取得目标页面正文或可确认的目标内容。
- 失效：目标地址返回 404、410，或页面明确说明内容已删除、下线、不存在。
- 未完成：本轮受到 403、429、502、超时、验证码或探针额度影响，还没有足够证据。

“未完成”不是“失效”。工具会把这些链接保留给“继续未完成”，不会要求你逐条人工分类。

二、怎么使用
------------

1. 双击“启动工具.cmd”。
2. 粘贴链接，或选择 Excel / CSV。
3. 点击“开始检测”。
4. 检测结束后查看“有效、失效、未完成”数量。
5. 基础核验结束后不会自动进入浏览器补证；如需继续提高确信覆盖率，点击“自动补证（数量）”。如页面列出知乎等平台，先完成一次登录或安全验证，再点击“登录完成 / 直接开始自动补证”；之后整批后台连续处理，不需要逐条操作。
6. 如果存在访问异常、超时或限流项，点击“继续未完成”。
7. 点击“导出结果”保存 CSV；从 Excel 导入时可以把结果写回原文件，写回前会自动备份。

主界面提供：

- 开始检测
- 继续未完成
- 停止
- 自动补证（基础核验结束后按需使用）
- 导出结果
- 打开链接
- 运行日志
- 运行状态、任务完成时间和总耗时

三、判定原则
------------

- HTTP 200 本身不够，必须同时取得文章标题、正文摘要或正文结构。
- HTTP 404、410 可以直接确认地址失效。
- 明确的“内容已删除、已下线、文章不存在”页面可以确认失效。
- 403、429、444、502、超时、连接失败、验证码和登录页都只算未完成。
- AI 不参与网络错误判断，也不会把错误页猜成有效或失效。

四、针对共享资讯站点
--------------------

部分站点在本机或境外线路返回 502，但中国普通宽带首次访问会返回防火墙 Cookie。
4.4 会自动：

1. 在中国普通宽带探针建立会话。
2. 携带 Cookie 再次访问原链接。
3. 如果仍然 403，立即合并新 Cookie 并重试。
4. 仍未成功时，为当前链接重新建立一次全新会话。
5. 按域名连续处理，尽量复用已经成功的会话。
6. 如果已经收到 HTTP 响应头，但正文分块传输中途断开，使用独立直连会话重新读取；遇到站点下发 Cookie 时携带 Cookie 再试。只有重新取得标题、正文、作者或目标编号证据后才判有效。

工具不再因为同一 IP 或同一域名连续出现 502 就跳过后续链接。

五、外部探针额度
----------------

中国普通宽带取证使用 Globalping。匿名额度用完时，结果显示“未完成”，不会显示“公网不可访问”。
v4.4.1 起，探针控制 API 使用本机直连出口，不再与目标网页的系统代理共享匿名额度。

如已取得 Globalping Token，可在当前 Windows 用户环境中设置：

GLOBALPING_API_TOKEN

设置完成后无需删除旧结果，重新打开工具或直接点击“继续未完成”即可。Token 不会写入日志、CSV 或断点。

六、结果文件
------------

CSV 只包含：

- 序号
- 链接状态
- HTTP 状态
- 页面标题
- 原链接
- 最终地址
- 检测说明
- 检测时间
- 单条耗时
- 任务开始时间
- 任务完成时间
- 任务总耗时

每次执行结束都会生成运行日志。发生问题时，把“最近一次执行日志.txt”发给维护者即可。

七、4.5 的主要变化
------------------

4.5.2 将验收目标改为确信覆盖率优先：

- 快速核验完成后立即结束，不再自动启动逐条浏览器深度复核。
- “自动补证”按钮直接显示候选数量；由使用者决定是否启动，启动后自动在后台连续补证。
- 不把速度作为验收目标，不通过缩短等待、降低证据标准或整个平台跳过来换取完成速度。
- 主界面和 CSV 明确记录任务开始时间、完成时间、总耗时。
- 验收线为“有效 + 失效”达到 95% 以上，“未完成”低于 5%；达不到时继续按平台分析和补证。
- 借鉴 lychee、Crawlee、LinkChecker、linkinator 和 changedetection.io 的缓存、持久队列、会话复用、重试退避与浏览器会话思路；平台内容判断仍使用本工具的证据规则。
- 平台规则继续按真实新台账扩展：已补充汽车之家车家号错误跳转、B站 Opus、新浪视频、汽车网评和西瓜视频等目标级证据；采集标题与网页标题不一致时，优先结合内容编号、正文和作者，不因只找不到标题判失效。
- 懂车帝仅在官方详情接口同时确认目标是文章、is_visible=false 且正文为空时判失效；QQ浏览器只接受目标 docId 的 410/作者删除页；贴吧删除响应须由系统代理和直连两路确认。知乎专栏、抖音图文、开封Plus、西瓜视频必须取得目标编号或目标路由以及匹配正文，供应商作者漂移不能作为删除证据。
- 发布前使用 59,502 条唯一链接的轮换池抽取全新样本，其中已纳入钉钉云文档的 6,779 条去重网媒链接；每批240条默认至少80条明确标注为“网媒”。重复批次、历史链接复用、网媒不足或抽不满指定数量都会直接失败。第22批再次更换240条全新链接，其中119条网媒；有效206、失效30、未完成4，确定率98.33%、未完成率1.67%，119条网媒全部取得确定结论。第24批（2026-07-29）更换240条全新链接，其中116条网媒；有效201、失效29、暂时异常5、人工复核5，确定率95.83%、未完成率4.17%，耗时2分46秒，并验证了 AutoVideo、360快资讯当前文章页和知乎回答删除空状态。旧批次回放不计入正式验收。

4.4.2 补充了跨电脑同步后的可靠性保护：

- 同一工作表同一行更换 URL 后会被视为新任务，不会误用旧结果。
- 主进度损坏时可从备份恢复；日志末行因中断不完整时，保留此前完整结果。
- 只有目标平台的最终地址返回 404/410 才能直接确认失效；跨站或登录页跳转不直接判失效。
- 关闭程序时等待最后一批结果写入断点。
- 支持没有 BOM 的 UTF-8 CSV，中文表头不会因编码误判而导入失败。

- 结果统一显示为有效、失效、未完成。
- 旧版“公网不可访问”会在升级后自动进入未完成续检。
- 502 不再触发整组提前跳过。
- Globalping 429 不再被错误归类为公网不可访问。
- 防火墙 Cookie 失败时会在同一轮刷新并重建会话。
- 同平台复用 Cookie 会话和访问状态；单条失败不会直接代表整个平台失败。

2026-07-29 第25批实验：再次使用240条全新链接，其中117条来自钉钉文档且标注为“网媒”。有效199、失效30、人工复核5、暂时异常6；确定率95.42%，未完成率4.58%，总耗时约4分10秒。该实验运行器会自动完成规则补证；桌面工具的快速核验结束后不会自动启动浏览器补证，仍由使用者点击“自动补证（数量）”决定是否继续。登录页、验证码、首页跳转和网络错误不会直接判为失效。

桌面工具说明：开始核验后先完成快速核验，结束后不会自动进入浏览器补证。需要进一步压缩未完成时，点击“自动补证（数量）”；若需登录或安全验证，集中完成后点击“登录完成 / 直接开始自动补证”，随后整批后台连续处理，无需逐条操作。

网络说明：开始核验后直接进入正式核验，不再额外做一轮开始前网络预检。这样可以避免同一链接被重复访问，也避免把登录页、风控页或临时网络异常误认为整批链接的网络状况。正式核验仍会按平台限速、记录异常、自动重试并保留断点；快速核验结束后是否启动浏览器补证，由使用者手动选择。

4.5.2 定向修复：搜狐旧版 `/v/` 分享链接只有在最终地址落到同站 404 页面时确认失效；顶端新闻分享页使用官方 `swnews.dingxinwen.com/api/news/getNewsInfo` 接口，目标编号、`n_del=0`、`n_only_me_see=0` 和非空正文同时存在即可确认有效，供应商标题为首句或作者为转载账号不会造成误判。生活圈 `/simple/` 的“文章找不到啦”作为目标级失效证据；互动易使用深交所公开详情接口；快速核验结束后不再自动打开浏览器，需手动点击“自动补证”。

4.5.5 规则修复：懂车帝返回空 body/纯 JavaScript 登录壳时也会进入一次有边界的公开补证，不再因壳页面没有“登录”文字而直接落入人工复核；雪球 WAF 空壳同样纳入公开补证。公开补证只有匹配目标正文/作者或明确目标删除提示才会给出确定结论。普通网媒的 502/超时仍保留为未完成，不会改写成失效；快速阶段仍不会自动打开浏览器。
