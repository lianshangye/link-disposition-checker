侵权链接处置核验工具 - 核验逻辑说明
================================

适用版本：4.1.0

这份文档说明工具在判断什么、靠什么证据判断、哪些平台有专用逻辑，以及哪些情况可能漏掉或只能留给人工复核。


一、工具实际判断的对象
--------------------

工具判断的是：核验当时，原链接指向的“目标内容”是否仍然可以确认存在。

目标内容不只是一整篇文章，也可以是：
- 新闻、图文、长文章
- 微博、雪球动态、股吧帖子、短帖
- 评论或回复
- 视频、音频、直播回放
- 平台分享页对应的原作品

工具不判断：
- 内容是不是负面
- 处置是否合法或是否达到业务要求
- 作者账号是否仍然存在
- 相同内容是否在其他地址被转载
- 历史人工记录今天是否仍然有效

作者账号被注销、改名、封禁或主页不可见，不能单独证明作品已删除。反过来，作者仍在也不能证明具体作品仍在。


二、输入字段分别有什么作用
------------------------

1. 原链接
   最核心字段。工具从地址中提取域名、内容编号、帖子编号、视频编号、回答编号和跳转关系。

2. 标题
   只是辅助证据，不要求逐字一致。平台改标题、采集标题是正文第一句话、帖子没有正式标题，都不会因为“找不到标题”直接判失效。

3. 摘要/正文片段
   用于确认短帖、评论、视频描述和标题不稳定的内容。雪球、微博、股吧、头条评论等有摘要时更容易确认目标仍在。

4. 发文作者
   用于增强身份匹配，尤其是内容编号、正文片段和作者同时出现时。作者字段缺失或不匹配不会单独判失效。

5. 平台、内容类型
   用于选择平台专用路径和解释结果。未知平台仍会走通用规则。


三、快速核验的执行顺序
--------------------

每条链接大致按以下顺序执行：

1. 校验链接格式，识别平台和内容类型。
2. 批量解析 DNS，将不同域名按公开 IP/平台归入共享基础设施组；同组统一排队，降低集中访问。
3. 读取原地址，依次比较系统代理和直连，记录 HTTP 状态、最终地址、响应类型和耗时。
4. 提取当前页面的标题、主体正文、可见文本、内容编号及错误状态。
5. 对已支持的平台，访问官方移动页、分享页、公开详情接口或同平台备用入口补证。
6. 首次访问遇到 502、超时或连接失败时，自动清理常见分享/统计参数后重试，并访问同站首页做健康对照。
7. 本机线路仍是临时失败时，把单条公开目标链接发送到内置无缓存公开云取证线路；不发送 Cookie、账号、工作簿或整批链接。
8. 使用者配置了独立远程取证节点时，继续从最多四个自有节点请求目标公开页面。
9. 本机系统代理、直连、同站对照和独立公网线路都无法连接目标时，输出“公网不可访问”；该结论不伪称已经看到了删除页。
10. 同站首页正常但目标内容仍异常，或者已经取得页面但证据有歧义时，自动启动持久 WebView2 浏览器追证。
11. 已经取得正文摘要且仍有歧义时，自动进入已配置的 Yunwu AI 收尾；错误页、验证码和登录页不发送给 AI。
12. 把所有证据统一分类，再由证据裁决器输出“已失效、仍可访问、公网不可访问、暂时异常、人工复核”。
13. 每完成一条立即写入断点进度；共享基础设施连续失败后的后续链接也会生成结果，不再静默跳过。


四、证据分为哪几类
------------------

工具内部把证据分为七类：

1. 目标内容存在
   当前目标页找到了目标编号，并由正文、摘要、标题、作者、媒体资源或正文结构确认内容仍在。

2. 目标明确失效
   当前目标主体明确显示删除、不存在、下架、作者删除、作品设为私密等状态，或官方详情接口明确返回目标已删除/不存在。

3. 目标已跳离
   原内容地址被明确跳到经过验证的平台错误页；或者回答/作品编号从最终目标地址消失，且该跳转形态已经按平台验证。

4. 访问受限
   登录、验证码、扫码、App 强制打开、403/429、安全验证、账号或设备风控。

5. 临时失败
   超时、5xx、连接重置、DNS 异常、证书拦截、代理失败、网络断开。

6. 通用网页外壳
   HTTP 200，但只有平台导航、推荐流、加载动画、通用标题或空白 JavaScript 外壳，没有目标正文身份。

7. 只有身份线索
   页面或接口只回显目标编号、旧缓存、分享参数，但没有当前正文或当前状态。


五、五种结果如何产生
------------------

已失效
满足以下一种高强度证据，且没有与之冲突的当前正文证据：
- 目标服务器当前返回 HTTP 404 或 410
- 进入已经验证的平台专用错误地址
- 官方当前详情接口明确返回目标不存在、已删除或已下架
- 目标正文/空状态主体明确显示目标已删除、不存在、下架或私密不可见
- 知乎回答等平台出现已经验证的“目标编号被跳离”形态

仍可访问
满足当前目标内容存在的强证据：
- 目标内容编号和主体正文相互确认
- 内容编号与摘要/标题/作者等多个身份字段相互确认
- 官方当前正文页返回目标编号和非空正文
- 视频、音频、图片等目标媒体资源当前可正常取得

公网不可访问
同时满足以下条件时，形成“核验不通过—公网不可访问”的明确业务结论：
- 本机系统代理和直连均未取得正常页面或正文
- 同站首页对照也不健康，无法证明只是单个内容地址异常
- 独立公网云线路明确报告目标连接失败、空响应或超时
- 同一共享基础设施至少两条代表链接得出相同结果后，剩余同组链接可复用该基础设施结论

“公网不可访问”表示公开网络无法核验交付内容，不等于工具看到了“已删除”页面。云服务自身限流、故障或 5xx 不会单独形成这个结论。

暂时异常
以下情况仍保留为可重试的临时结果：
- 只有本机线路失败，独立公网证据尚未达到阈值
- 云取证服务自身报错、限流或暂时不可用
- 线路证据不足以区分目标故障和取证线路故障

人工复核
出现以下任一情况时不硬猜：
- 登录、验证码、扫码、App 限制、403、429、风控
- 只有首页、推荐流、通用标题、空壳页或加载页
- 只在缓存接口中看到目标编号，没有当前正文
- 目标存在证据和目标失效证据互相冲突
- 未知平台或平台改版后没有足够身份依据

界面、CSV、断点和执行日志保留这五种状态。写回原 Excel 时，“已失效/仍可访问/公网不可访问/人工复核”分别写为“是/否/公网不可访问/待复核”；输入有误和疑似已处置仍按待复核处理。


六、证据优先级和防误判规则
------------------------

1. 当前目标正文高于页面其他区域
   只要目标文章、帖子或视频正文仍存在，评论区、相关推荐、侧栏、弹窗中的“已删除/已下架”不能推翻它。

2. 明确目标失效高于普通 HTTP 200
   很多平台删除内容后仍返回 200。工具会继续看错误页、主体空状态、目标编号和平台接口，不能把 200 当作有效。

3. 登录和风控不是失效证据
   401、403、429、验证码、登录窗口、扫码或 App 提示只说明当前电脑没看到内容。

4. 标题缺失不是失效证据
   采集标题可能是第一句话；帖子、评论和视频也可能没有网页标题。标题只参与身份确认，不承担“找不到就下架”的规则。

5. 缓存和编号回显不能单独判有效
   分享参数、页面脚本、旧接口缓存或通用外壳可能保留已删除作品的编号。必须再确认当前正文或当前状态。

6. 证据冲突时不选择一边
   如果当前响应同时出现可靠正文存在证据和可靠失效证据，结果进入人工复核，避免误判。

7. 作者状态只作辅助
   作者消失、账号注销、账号改名、主页无法打开均不能单独决定作品状态。


七、平台专用核验范围
------------------

以下是当前已知平台族。平台会改版，表中“已覆盖”表示已有专用入口或规则，不表示任何情况下都能自动判断。

1. 东方财富、股吧、财富号、天天基金
   使用帖子编号、文章编号、官方移动正文页和公开帖子接口。股吧只有官方接口明确不存在/删除或进入 error?type=2 等已验证错误状态才判失效；账号注销不能推翻正文仍在。

2. 同花顺
   短帖、评论和长文章分别读取对应公开详情接口，核对 content_id、正文和状态。接口受限或异常时保留人工复核。

3. 腾讯系
   腾讯自选股读取真实新闻 ID 和公开新闻接口；腾讯新闻使用官方移动正文/分享正文页；腾讯视频读取官方视频信息。视频号强依赖微信环境时保留人工复核。

4. 百度新闻、百家号、好看视频、有驾
   使用百度系共享内容 ID、当前公开正文页和专用错误页交叉确认。接口缓存只作辅助，不能单独判仍可访问。

5. 今日头条
   分享短链先完成同平台跳转，再按最终文章/视频编号核对公开内容信息和当前正文。只剩推荐流时不能直接判下架。

6. 抖音
   不把登录窗口当作失效。核对作品编号、公开分享页、作品描述和明确不可见状态。滑块或设备风控进入人工复核。

7. 微博
   核对微博编号、正文片段和公开作品状态。通用登录页、推荐流或风控页不能决定结果。

8. 知乎
   登录弹窗本身不是失效。回答链接明确跳回同一问题、目标回答 ID 从最终地址消失，或目标主体显示经过验证的不存在空状态时可判失效；安全验证时暂停该平台并保留进度。

9. 雪球
   支持标题是正文首句、没有正式标题的动态。核对状态编号和正文片段；只有通用标题/登录外壳时保留人工复核。

10. B站
    视频和动态分开处理。动态优先访问官方 Opus 页面，要求动态编号、正文片段、作者等身份相互确认。通用“动态-哔哩哔哩”外壳或验证码不判有效。

11. 网易
    普通内容按当前正文和 404/410 判断；网易视频会结合官方视频详情和视频页。单独登录页或通用外壳不判下架。

12. UC头条、大鱼号
    读取官方移动页中的 aid、标题和作者；目标 aid 明确返回“文章不存在”时判失效。

13. 搜狐
    使用当前官方移动正文页。目标文章明确跳到 /404.html 时判失效；页面其他区域出现“页面不见了”不算。

14. 新浪、一点资讯、凤凰、快资讯
    已覆盖各自明确文章不存在页和专用 404 跳转，例如新浪“该文章已不存在”、一点资讯“文章没有找到哦”、凤凰 hotNewsShare404、快资讯 /pc/404.html。

15. 汽车之家、易车、车家号
    尝试官方移动/内容页，核对内容编号、标题、正文和作者。只有通用页面时不硬判。

16. 爱奇艺
    使用公开索引页核对视频编号、原标题和发布者。只有通用播放外壳时证据不足。

17. 大智慧、顶端柘城
    分别核对公开页面数据中的文档编号/Found 状态，以及公开详情接口中的目标 uuid 和存在状态。

18. 小红书
    当前网页能取得目标正文时可判仍可访问；分享跳转明确包含“该内容暂时无法查看”可作为失效证据；扫码、App、登录或只能手机查看时进入人工复核。

19. 快手、喜马拉雅、ZAKER
    普通请求经常只得到通用外壳、加载页或验证码。工具会尝试官方内容入口，但未取得目标正文或明确错误状态时保留人工复核。

20. 懂车帝、微信、微信视频号
    公开网页与登录/客户端环境差异较大。能够取得目标正文时按正文判断；强制登录、微信环境或 App 环境时保留人工复核。

21. 其他未知平台
    仍会检查 HTTP 404/410、重定向、目标编号、标题/摘要/作者和主体失效提示。但没有平台专用接口或错误页知识时，动态外壳和模糊提示更容易进入人工复核。


八、platform-rules.json 能扩展什么
--------------------------------

便携包的 x64、x86 文件夹中各有一份 platform-rules.json。它可以在不重新编译的情况下增加：
- 平台名称和域名/子域名
- 登录入口
- 是否属于动态网页外壳
- 深度复核等待时间和平台分组
- 已验证的删除提示
- 登录、验证、风控提示
- 平台限制说明

它不能单独完成复杂接口解析。新平台如果需要签名参数、特殊内容 ID、多个官方接口交叉验证或特殊重定向判断，仍需要修改程序并重新测试。

删除提示不能只因为“这个词出现过”就直接判失效。程序仍会检查该提示是否属于目标主体，并检查当前正文证据是否与它冲突。


九、深度复核实际做什么
--------------------

1. 使用 Windows 的 WebView2 建立可持续的内置浏览器会话。选择它是因为 WinForms 可以稳定嵌入、控制加载、读取页面并保留同一登录态；这不要求使用者把 Edge 设为日常默认浏览器。
2. 允许使用者先登录可能有帮助的平台，但登录不是所有平台的前提。
3. 先并发取得公开响应和平台接口，只对确实可能受益的平台做短渲染或持久渲染。
4. 开始后自动最小化，处理完一条继续下一条，不等待使用者逐条“跳过”。
5. 每条深度复核结果立即保存；中断后仍可继续。
6. 遇到平台持续安全验证时停止继续刺激该平台，避免整批触发更严重风控。
7. 大批量网络预检只记录异常分布并安排共享基础设施节奏，不再要求使用者选择继续或暂停，也不会全局中断其他站点。

深度复核不是“打开浏览器就一定能解决”。强制 App、微信私域、验证码、地区限制、账号权限和单位网络策略仍可能无法自动确认。
“暂时异常”会先完成本地多线路、规范化链接、同站对照、内置公开云和可选自有节点追证。同站首页正常而目标页异常时会进入内置浏览器；整站/共享基础设施均异常时不再重复浏览器刷新。多出口证据达到阈值后转为“公网不可访问”，未达到阈值的记录可点击“重试访问异常（数量）”重跑。单个 HTTP 5xx 只能证明某条线路或目标服务器没有返回正常页面，不能单独证明内容已失效或触发风控。


十、明确可能漏掉或判断不了的情况
------------------------------

1. 平台刚改版，原错误页、接口、正文结构或域名发生变化。
2. 新平台、新短链接域名、新内容类型尚未加入规则。
3. 只有登录账号、好友关系、付费权限、地区权限或手机 App 才能看到内容。
4. 单位代理、证书替换、安全软件或白名单阻止普通程序联网。
5. 页面返回的是旧缓存，且缓存内容与当前真实状态不一致。
6. 供应商给出的链接、标题、摘要、作者本身错误或对应错行。
7. 评论被折叠、仅作者可见、限流、搜索不可见，但原链接状态没有明确提示。
8. 作品被作者隐藏/设为私密，但平台只给通用登录页或模糊提示。
9. 同一内容被重新发布到新链接；工具只判断原链接，不自动追踪替代地址。
10. 网络短时波动导致超时或 5xx；这类结果不会直接判已失效，会先完成自动追证，再根据多出口证据进入“公网不可访问”或“访问异常待重试”。

对于这些情况，工具会区分“访问证据尚不可得”和“已取得页面但证据冲突”，而不是为了降低数量随意判成有效或失效。


十一、作品隐藏或作者删除如何处理
----------------------------

对外保留“已失效、仍可访问、公网不可访问、暂时异常、人工复核”五种可审计状态：

- 平台在目标主体明确提示“作者已删除、作者已设为私密、作品不可见”，可归为“已失效”。判定依据会保留具体提示。
- 只有作者账号消失、登录页、权限不足或模糊的“暂不可见”，无法确认是删除、隐藏还是访问限制时，归为“人工复核”。
- 目标正文仍然清楚存在，即使作者主页异常，仍归为“仍可访问”。


十二、如何审计工具的结论
----------------------

每条结果会保留：
- 原链接
- 最终地址
- HTTP/平台状态
- 页面标题
- 平台和内容类型
- 发文作者辅助字段
- 判定依据
- 核验时间和耗时

每次执行还会生成一份任务级诊断日志，记录：
- 工具版本和唯一运行编号
- 执行类型、启动方式、开始/结束时间和结束原因
- 本次及累计结果分布
- HTTP 状态、失败类型、平台和域名汇总
- AI 调用数量、模型和自动确认数量
- AI 请求、重试、成功、失败次数和关键执行事件
- 最多 30 条匿名问题样本
- 基于本次比例生成的诊断提示

任务级日志用于版本迭代，不作为单条链接失效的最终证据。日志不会保存 API Token、Cookie、完整正文或完整链接。
每个用户目录最多保留 100 份历史执行日志，另有一份“最近一次执行日志.txt”便于反馈。

“判定依据”是最重要的审计字段。抽查时应优先看它是否描述了目标正文、目标编号、官方错误状态或访问限制，而不只看最后的“是/否”。


十三、AI 辅助复核的边界
----------------------

AI 辅助复核是可选的二次证据阅读层，只处理“机器规则尚未确认，但当前响应已经取得足够页面正文摘要”的候选项。它不自行打开网页，也不补充外部搜索结果。

进入 AI 复核前必须同时满足：
- 原结果是“人工复核”或“疑似已处置”
- 当前 HTTP 状态为 2xx 或 3xx
- 已保存足够的当前页面可见正文摘要
- 没有验证码、登录、扫码、App 限制、403/429、超时、5xx 或网络限制信号

AI 批处理采用失败隔离：
- 单条调用暂时失败时最多重试一次
- 单条最终失败不会标记为已复核，稍后仍可继续
- 连续 3 条失败才暂停整批，避免持续限流或网络故障扩大
- Token、额度、API 地址或模型权限等明确配置错误立即停止

发送给所配置 Yunwu API 的字段限于：原链接、最终地址、平台、内容类型、HTTP 状态、预期标题/摘要/作者、当前页面标题、机器判定依据、最多约 6500 字的当前可见正文摘要和有限的证据轨迹。不会发送 Cookie、账号、密码、浏览器凭证或完整工作簿。

模型结果必须通过本地安全门：
- “仍可访问”只有在模型置信度至少 95%，且本地再次核对到目标标题、正文片段或作者身份时，才可改为确定结果
- “已失效”即使模型置信度至少 97%，也只会在页面已有明确删除提示时标为“疑似已处置”，不能单独形成确定的“已失效”
- 其他模型建议只记录在判定依据和 AI 审计字段中，原结果保持不变

这套设计的目标是减少“网页已经取得正文但规则没有覆盖”的人工复核，不用于绕过平台风控。AI 模型仍可能理解错误，因此抽查应同时看当前页面证据、AI 建议、置信度和最终判定。


十四、当前样本基线应怎样理解
--------------------------

2026-07-26 使用真实办公批次的 1521 条去重有效链接做了完整核验。
快速核验结果：已失效 8、仍可访问 712、公网不可访问 769、暂时异常 7、证据待复核 25，明确结论覆盖率 97.90%。
随后对剩余 32 条实际运行自动 WebView2 和已配置 AI 收尾，新增确认仍可访问 12 条；合并结果为已失效 8、仍可访问 724、公网不可访问 769、证据待复核 20，明确结论覆盖率 98.68%。

这说明 4.1 在该真实批次中完整处理了 1521/1521 条，没有中途停止，并把未形成明确结论的比例降到 1.32%。它是“明确结论覆盖率”，不是与人工真值逐条比对后的准确率；“公网不可访问”也不等于明确删除。新平台、新网络环境和未来网页状态仍可能改变结果。

历史人工列只代表当时的人工快照。过去标记“未下架”的内容今天可能已经删除，过去标记“下架”的链接也可能恢复、换页或被重新发布。工具始终以核验时取得的当前证据为准。
