链接失效检测工具 - 核验逻辑
============================

适用版本：4.5.5

一、唯一目标
------------

判断当前链接是否还能取得目标内容。

输出只有三种：

- 有效
- 失效
- 未完成

二、有效
--------

满足以下任一可靠证据：

- 当前原地址返回正常页面，并取得有效标题以及正文摘要或正文结构。
- 平台公开内容接口返回与目标内容编号一致的正文数据。
- 经过浏览器渲染后取得与目标链接一致的正文。

普通首页、空壳页、登录页、验证码页和 HTTP 200 错误页不能判定有效。

三、失效
--------

满足以下任一明确证据：

- 当前目标平台的最终地址返回 HTTP 404 或 410；跨站跳转或登录页返回 404/410 不直接判失效。
- 当前页面明确显示文章不存在、内容已删除、作品已下线等。
- 平台公开接口明确返回目标内容不存在。

四、未完成
----------

以下状态均为未完成：

- HTTP 403、429、444、5xx
- 超时、连接失败、DNS 或 TLS 异常
- 验证码、登录限制、App 强制打开
- 外部探针额度不足
- 页面有响应但无法确认目标正文

未完成项始终保留在续检队列。

五、检测顺序
------------

1. 原地址普通请求。
2. 清理分享和统计参数后重试。
3. 同站首页健康对照。
4. 中国普通宽带防火墙会话。
5. Cookie 更新后同探针重试。
6. 为当前链接重新建立全新会话。
7. 已收到响应头但正文读取中断时，用独立直连会话重新读取；接收并携带站点 Cookie 再试。
8. 公开云浏览器取证。
9. 必要的内置浏览器渲染。

任何阶段取得正文或明确失效证据后立即结束该链接。

六、批量策略
------------

- 基础核验按保守访问节奏执行，不以缩短用时为目标。
- 开始核验不再额外进行网络预检，直接进入正式核验；正式流程仍按平台限速、异常重试和断点记录处理网络问题，避免重复访问和临时页面误判。
- 基础核验完成后停止。内置浏览器补证必须由使用者点击“自动补证（数量）”启动；点击一次后自动连续执行，无需逐条等待或再次点击继续。
- 502 不触发域名或共享 IP 整组跳过。
- 只有目标站点直接返回 403、429、444 或明确安全验证时，才允许短暂保护性暂停该域名。
- 外部探针 429 只表示探针容量不足，不表示目标链接不可访问。
- 规则版本升级时会重跑受影响的旧结论；4.5.2 保留 4.4.2 及之后已经确认的有效和失效，其他结果进入续检。

七、界面和导出
--------------

主界面只展示链接检测所需信息：

- 状态
- HTTP
- 页面标题
- 原链接
- 最终地址
- 检测说明
- 检测时间

“自动补证”按钮只负责按需启动浏览器补证，不会在基础核验结束后自动运行。首次或会话失效时，可在开头完成一次平台登录/安全验证，再点击“登录完成 / 直接开始自动补证”；后续复用持久浏览器会话，并按“原始响应、平台公开接口、稳定页面渲染”继续追证。

CSV 输出链接状态、HTTP 状态、页面标题等检测字段，并附任务开始时间、任务完成时间和任务总耗时。

验收目标是有效与失效合计达到 95% 以上、未完成低于 5%。该目标是覆盖率门槛，不允许通过降低证据标准、把登录页判失效或把页面外壳判有效来凑数。

工程结构借鉴 GitHub 开源项目 lychee、Crawlee、LinkChecker、linkinator、changedetection.io 的结论缓存、持久任务、Cookie/会话复用、分阶段重试和持久浏览器思路。开源项目不提供中文平台内容是否删除的现成结论，因此最终有效/失效仍由本工具的平台身份和失效证据规则决定。

八、正式实验数据
----------------

- 固定旧样本只用于回归，不作为达标证明。
- 正式实验从 59,502 条唯一链接池中轮换抽取，默认每批 240 条；钉钉云文档提供6,779条去重网媒链接，正式批次默认至少包含80条明确标注为“网媒”的样本。
- 每条历史内容链接永久记账；忽略 http/https、锚点、参数顺序和常见分享追踪参数后的同一内容不会再次进入正式批次。
- 重复批次种子、历史复用不为 0、或新链接不足 240 条时，正式实验直接失败。
- 2026-07-28 第 18 批 240 条全新链接以 94.17% 确定率失败，暴露并修复了两个官方证据解析缺口；修复后的第 19 批再次更换 240 条全新链接，以 97.08% 确定率、2.92% 未完成率通过。旧批次回放不计入正式验收。
- 第20批加入大量网媒后以95.00%确定率、5.00%未完成率严格判定失败；修复“响应头已到但正文传输中断”的恢复路径后，第21批再次抽取240条未见链接，其中126条网媒、历史复用0条，以95.83%确定率、4.17%未完成率通过。该结果只证明轮换覆盖率门槛通过，不替代当期人工真值准确率验收。
- 第22批再次抽取240条未见链接，覆盖68个平台、161个域名，其中119条明确标注为网媒、历史复用0条。结果为有效206、失效30、未完成4，确定率98.33%、未完成率1.67%；119条网媒全部确定。该批用于验证网媒标题“或/斜杠”排版差异、懂车帝隐藏文章、知乎专栏、QQ浏览器作者删除页、抖音图文、西瓜视频、贴吧和开封Plus的目标级证据。

平台边界补充：供应商标题可能是正文首句，作者也可能是转载账号，因此标题或作者不一致本身都不是失效证据。懂车帝隐藏文章要求官方接口返回 is_visible=false 且正文为空，并由系统代理和直连复核；贴吧明确删除响应也须两路确认。QQ浏览器要求目标 docId 对应 410/作者删除页。抖音图文通过页面实际调用的官方详情接口核对作品编号、图文正文和作者；知乎回答只有官方“没有知识存在的荒原”并提示回答页不存在时判失效，知乎专栏、西瓜视频和开封Plus要求目标编号或目标路由与匹配正文同时成立。AutoVideo 要求原始 id、匹配标题/摘要和视频时长、评论/相关推荐等详情结构；360快资讯要求原始内容编号、og:type=news 和匹配标题/摘要。验证码、登录页和普通空壳仍保留未完成。

九、断点可靠性
--------------

- 任务身份由工作表、行号和 URL 共同组成；同一行换链接不会沿用旧结果。
- 主进度、备份和追加日志共同恢复已完成记录。
- 日志最后一行因断电或强制退出损坏时，忽略该残行并保留此前完整结果。
- 用户关闭程序时先停止任务、接收队列中最后一批结果并保存，再真正退出。

钉钉网媒样本补充：钉钉文档导出的记录中，网媒只是供应商标签，不是一个平台。正式抽样继续按真实域名、页面结构和平台特征拆分；2026-07-29 第08批使用240条全新网媒样本，覆盖169个域名，确定率98.33%，未完成率1.67%。
钉钉网媒第11批补充（2026-07-29）：240条全新网媒样本按真实域名分层验证，结果有效236、失效3、暂时异常1，确定率99.58%，未完成率0.42%，耗时约1分09秒。琼海视窗等站点会先返回空正文 HTML，再由同站 /ajaxContent 接口加载正文；只有接口 code=200 且返回足量文章正文时才提供“仍可访问”证据，供应商标题不匹配不会单独导致失效，空壳或接口异常继续保留未完成。
共享基础设施边界（第12批修复）：不同网媒域名可能解析到相同云主机 IP，但虚拟主机、站点程序和访问策略彼此独立。共享 IP 只能用于请求节奏和基础设施记录，不再作为跨域暂停、跳过或复用失败结论的分组键。第12批错误版本产生33条暂时异常；按真实域名独立核验后，同批结果为有效238、失效1、暂时异常1，确定率99.58%、未完成率0.42%，耗时3分15秒。该修复不降低有效/失效证据门槛，只确保每个域名实际接受核验。
第13批混合平台补充：240条全新样本覆盖80个平台、155个域名，其中97条网媒。结果有效203、失效27、未完成10，确定率95.83%、未完成率4.17%，耗时7分31秒。花城+分享页为 JavaScript 空壳，当前前端调用 `https://app.gztv.com:7443/gzbn-cloud-manuscript-app/app/article/plusDetail/{manuId}`；只有接口返回 code=200、目标 manuId、匹配标题和完整正文时才判有效。微信验证页、知乎403风控、快手空壳、整站521、视频号无公开页和首页跳转仍保留未完成。
第14批混合平台补充：240条全新样本覆盖64个平台、166个真实域名，其中131条来自钉钉文档并标注为网媒，历史复用0条。首次结果有效199、失效31、未完成10，确定率95.83%、未完成率4.17%，耗时3分44秒；131条网媒全部确认有效。同花顺文章只有官方详情接口明确返回 `status_code=-30003` 且 `文章审核未通过` 时才确认当前不可公开访问；定向回放该条后，按原批次其余结果不变换算为有效199、失效32、未完成9，确定率96.25%、未完成率3.75%。普通接口错误、网络错误或空白页继续保留未完成。
4.5.2 边界补充：搜狐旧版 `/v/` 分享页需验证最终 URL 为同站 404，不能仅凭标题文字；顶端新闻分享页的官方接口需同时返回目标 `n_id`、`n_del=0`、`n_only_me_see=0` 和非空 `n_content`，标题或作者只作为正向辅助信号。生活圈 `/simple/` 的“文章找不到啦”属于目标级失效证据；互动易以 `newircs/question/getQuestionDetail` 返回的目标问题正文和提问账号确认有效。接口状态不完整、正文为空或网络错误仍为未完成。快速核验完成后不自动进入浏览器补证，用户通过“自动补证”按钮手动启动。
2026-07-29 第16批钉钉网媒扩展样本：240条全新链接，227条标注为“网媒”，覆盖193个真实域名，历史复用0条。结果仍可访问237、已失效3、未完成0，确定率100%，耗时1分25秒。复盘发现网媒站点可能返回HTTP 403但正文/标题含“404”字样；这类安全拦截不得直接判为失效，只有HTTP 404/410、明确错误路由或平台目标级删除证据才能确认失效。

2026-07-29 第17批混合平台扩展样本：240条全新链接，覆盖76个平台标注、160个真实域名，其中108条标注为“网媒”，历史复用0条。结果仍可访问198、已失效31、暂时异常5、人工复核6，确定率95.42%，未完成率4.58%，耗时4分23秒。失效结论均有HTTP 404/410、平台官方接口、明确删除/隐藏页或目标级错误页；知乎403、微信验证页、快手空壳、搜狐时间线和超时页面保留未完成。

边界规则补充：英文或中文安全拦截页（403、Access Denied、Forbidden、Captcha、安全验证、网站防火墙等）优先按访问限制处理；即使同页同时出现“404”或“Page Not Found”，也不得直接判为失效，除非最终地址、HTTP状态或平台专用接口提供目标级失效证据。
钉钉文档网媒扩展（第47批，2026-07-29）：入口需要登录，因此入口地址只作来源登记，实验读取已导出的本地副本。240条全新样本中181条标注为“网媒”，覆盖175个真实域名且历史复用0条；有效216、失效19、暂时异常3、人工复核2，确定率97.92%，未完成率2.08%，耗时约3分37秒。181条网媒全部确定。该批再次确认：网媒标签不是平台名，必须按真实域名、目标正文/摘要、作者、文章编号及目标级错误页综合判断。
第48批混合平台复验（2026-07-29）：240条全新链接，覆盖72个平台和161个真实域名，其中110条网媒，历史复用0条。有效197、失效37、暂时异常3、人工复核3；确定率97.50%，未完成率2.50%，耗时约4分18秒。网媒子集110条全部确定。微信验证页、知乎403、快手目标身份不足、腾讯视频超时、360doc超时继续保留未完成；访问限制、站点首页不可用和网络超时不是下架证据。


4.5.3 取证边界：公共中国宽带探针存在共享小时额度，默认不作为每条普通网媒 403/502 的自动步骤；快速阶段先完成本机请求、同站健康对照和平台专用接口，探针仅在用户明确开启 LINK_CHECKER_ALLOW_CHINA_EYEBALL=1 或特定基础设施场景下使用。探针额度耗尽只产生可重试异常，不代表失效。
4.5.5 平台补证：知乎、百家号、雪球和懂车帝在普通网页/API进入 403、验证页、WAF 空壳或空 body 时，可调用一次有边界的独立公开读取。有效结论必须匹配目标编号及标题、正文或作者；失效结论必须出现目标级错误提示，例如知乎“没有知识存在的荒原”或雪球“原帖已被作者删除”。懂车帝登录壳、微信验证页、微博通用错误页和微信视频号过期下载地址仍不是失效证据；公开读取未取得目标证据时仍保留人工复核。
